# Ritxx Watch

**Find your next favorite story.**

Ritxx Watch is a personalized movie and series discovery app. Search supported catalogs, explore titles, and keep track of what you want to watch—all in a bold, dark Ritxx interface.

## Highlights

- Browse and search movies and series
- Explore title details and supported catalogs
- Keep track of saved titles, downloads, and viewing history
- Enjoy a personalized Ritxx design

## About this project

Ritxx Watch is an independent customization based on the open-source OpenStream project. It does not host or own movies or series; catalog and playback availability depend on supported external sources. Original project credits and license terms are retained.
